## 4. 探した方法

1. ユーザーPC上（Cowork のローカル Linux 環境）で Python 3 を使用し、フォルダ直下の Excel ファイル 101件を列挙（`_検証結果` は除外）。ファイルは読み取りのみ。
2. **.xlsx**: zipfile で全 XML パーツを展開せずに読み取り、
   - 全パーツを対象に「ペリカン承認」を検索（タグ除去・空白除去・NFKC 正規化版でも検索し、書式で分断された文字列や表記ゆれも検出）
   - 位置特定用に、sharedStrings／各シートのセル値・数式・入力規則・ヘッダー/フッター、シート名と表示状態（hidden/veryHidden）、名前の定義、コメント、図形（DrawingML の sp/pic/graphicFrame の名前・テキスト・代替テキスト）、グラフ XML、文書プロパティ（core/app/custom）を個別に解析。
3. **.xls**: xlrd でセル・シート・表示状態を読み取り、さらにバイナリを UTF-16LE / CP932 で直接検索。図形・コメントの位置特定のため、作業用コピーを LibreOffice（headless）で xlsx に変換して 2. と同じ解析を実施（元ファイルは変更せず）。
4. **画像**: 画像を含む 26ファイルをクラウド作業環境にコピーし、xl/media 内の画像を取り出して一覧画像を作成し目視で読み取り（日本語OCRは利用不可のため）。写真風画像はエッジ検出で隠れ文字を確認。
5. 暗号化ファイルは `file` コマンドで暗号化を確認。
