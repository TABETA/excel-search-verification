# Excel ナレッジ（作成・更新・問い合わせ回答）

Excelファイル群を、出典つきのMarkdownナレッジに一度変換しておき、問い合わせはそのナレッジを根拠に答える。画像の書き起こしは作成時に一度だけ行う。

## 共通ルール
- 元のExcelファイルは読むだけにする（変更・保存しない）。
- ナレッジの置き場所は、ユーザーの指定がなければ `<対象フォルダ>/_knowledge`。スクリプトはこのフォルダを自動で検索対象から外す。
- 回答の根拠はナレッジ（＝対象のExcel）だけ。一般知識や推測で空白を埋めない。過去のチャットは参照しない。

## A. ナレッジの作成・更新

1. このスキルの `scripts/excel_to_kb.py` を作業ディレクトリにコピーする。
2. 実行する：`python3 excel_to_kb.py build <対象フォルダ> <ナレッジフォルダ> [--exclude 除外サブフォルダ名...]`
   - 変更されたファイルだけ読み直す（サイズと更新日時で判定）。削除されたファイルはナレッジからも消す。
   - 書き起こし済みの画像は、画像の中身が同じなら引き継ぐ。
   - .xls は LibreOffice があれば一時変換して読む。無ければ「読めなかったファイル」に載る。
3. **未記入の画像を全部書き起こす。**
   - `python3 excel_to_kb.py pending <ナレッジフォルダ>` で一覧を出す。
   - 各画像を Read ツールで実際に見る。見られない環境なら、画像を見られる環境へコピーしてから見る。小さい文字や薄い文字は拡大して確認する。
   - 書き起こしは `python3 excel_to_kb.py set-image <ナレッジフォルダ> <doc_id> <画像番号> "<内容>"` で記入する。Markdownを手で書き換えない。
   - 書き起こす内容は、画像内の文字をすべて（数値・単位・注記を含む）。図なら、何を示す図か、矢印や引き出し線が何を指しているかも1〜2文で添える。文字が無い画像は `-` を記入する。
   - 残りが0枚になるまで続ける。
4. `index.md` を見て、読めなかったファイル（暗号化など）があればユーザーに伝える。

## B. 問い合わせへの回答

1. ナレッジが無い、または対象フォルダに更新がありそうなら、先に A を行う（`build` は差分だけなので速い）。
2. `index.md` で文書の一覧をつかむ。
3. 質問の語句と、その言い換え（品番・部品番号・略称・漢字/カナの違い、例：シャフト→S-201）で `docs/*.md` を grep する。見つかった文書の md は全体を読む（1文書は小さい）。
4. 文書ごとの注意。
   - **集計・件数・合計**は、目で数えず `tables/.../*.csv` を Python で読んで計算する。表の上や下にある注記（例：「キャンセルは集計対象外」「税抜」）を条件として必ず適用する。期間・顧客などの絞り込み条件も、答えに明記する。
   - **新旧の食い違い**を確認する。版数・施行日・「旧版」ファイル・非表示シートの改訂履歴・セルのコメント（「〜より切替」等）・変更管理表は、表の値より新しい情報であることが多い。最新の情報で答え、古い情報と食い違うことを一言添える。
   - **工程の順番・分岐**は「フロー（図形をつなぐ矢印・線）」の節を使う。図形が並んでいる順番は、工程の順番ではない。
   - **ファイルをまたぐ質問**（例：不具合報告の受注No → 受注一覧の顧客）は、ID・番号で突き合わせる。
5. 回答の形式。
   - 結論を先に、簡潔に書く。
   - 根拠を付ける：ファイル名＋シート＋セル/図形名/コメント/画像番号。
   - 計算した場合は、条件と計算方法を1行で書く。
   - **見つからない場合は「ナレッジ内に記載なし」と答え**、どの語句でどの文書を探したかを書く。近い情報があれば、それと区別して示す。
   - 推測を含む場合は、事実と推測を分けて書く。

## ナレッジの構成
- `index.md`：文書一覧（シート・非表示シート・画像数・未記入画像）と、読めなかったファイル
- `docs/<doc_id>.md`：1ファイル1文書。セル（表形式。大きい表は行ごと）、非表示シート/行/列、結合セル、コメント、図形・テキストボックス（グループ内も）、フロー（矢印のつながり）、グラフ、入力規則、ヘッダー/フッター、名前定義、プロパティ、画像とその書き起こし
- `tables/<doc_id>/<シート>.csv`：シート全体の値（1行目＝Excelの1行目、A列から。数式は計算結果、日付は yyyy/mm/dd）
- `images/<doc_id>/`：抽出した画像
- `model/`、`manifest.json`：差分更新用（触らない）
