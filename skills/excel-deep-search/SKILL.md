# Excel 深掘り検索

フォルダ内の .xlsx / .xlsm / .xls から指定語句を探す。テキストとして入っている箇所はスクリプトで機械的に拾い、画像の中の文字は必ず目視で読む。この2段構えを毎回省略せずに実行する。

## 守ること
- 元のExcelファイルは読むだけ。変更・上書き・削除・Excelでの保存はしない。
- 検索結果や作業用ファイルは対象フォルダの外に置く。置けない場合は専用サブフォルダに置き、`--exclude` で検索対象から外す。
- 根拠は対象ファイルだけ。過去のチャットは参照しない。

## 手順

1. このスキルの `scripts/excel_deep_search.py` を作業ディレクトリにコピーする（対象フォルダの中には置かない）。
2. 実行する。
   ```
   python3 excel_deep_search.py <対象フォルダ> <語句> [<語句2> ...] --out <出力先> --exclude <除外するサブフォルダ名...>
   ```
   - 標準ライブラリだけで動く。Pillow があれば画像の一覧（contact sheet）を作る。無ければ `pip install pillow` を試す。
   - LibreOffice（soffice）があれば、.xls を一時コピー上で xlsx に変換し、図形やコメントまで解析する。無ければ .xls は生バイト検索のみになるので、報告にそう書く。
3. `<出力先>/result.json` を読む。
   - `hits`：完全一致。書式違いで分割された語は結合済みで、場所の表記つき。
   - `near_variants`：表記ゆれ候補。全角/半角、ひらがな/カタカナ、空白・改行・段落による分断が対象。
   - `locked`：暗号化されていて開けないファイル。
   - `errors`：読めなかったファイル。
   - `images`：抽出した全画像。id、元ファイル、シート、画像名、代替テキストを持つ。
4. **画像は全部見る（省略しない）。**
   - `contact_*.png` をすべて Read ツールで表示する。画像を見られる環境に無ければ、先にコピーしてから見る。
   - 各タイルの `#id` を `images` と突き合わせる。
   - 文字が小さい、薄い、傾いている、ノイズが多いタイルは、`images/<id>.*` の元画像を等倍か拡大・切り抜きで見直す。
   - EMF/WMF など Pillow で開けない画像は、LibreOffice で PNG に変換して見る。それもできなければ「未確認の画像」として報告する。
   - 日本語OCR（tesseract の jpn）が使えれば補助に使ってよいが、目視を省略しない。
5. 判定。
   - 完全一致（語句がそのまま連続して含まれるもの。前後に別の文字が付いていてもよい）を「該当」とする。
   - 表記ゆれと、隣り合うセルに分かれているものは「参考」として該当とは別に挙げる。
   - 似ているが別の語（例：承認と承諾）は該当にしない。
6. 報告する（ユーザーが出力先を指定していればそこにも書き出す）。
   1. 該当ファイル一覧：ファイル名、場所（シート名・セル番地・図形名・グラフ・コメント・画像など）、見つけた文字列。1ファイルに複数箇所あればすべて。画像内の文字で見つけたものは別の表にする。
   2. 参考（表記ゆれ・分断）。
   3. 画像：調べた枚数、読み方、読めなかった画像。
   4. 開けなかったファイルとその理由。暗号化ファイルは中身が不明であることを明記する。
   5. 探し方の要約と所要時間。

## スクリプトが見ている場所
セル（共有文字列・インライン・数式とそのキャッシュ値、非表示・veryHidden シート、非表示行・列、白文字、遠方セル）、シート名、名前定義、入力規則、ヘッダー/フッター、コメント（メモ・スレッド）、図形・テキストボックス（グループ化の入れ子、書式違いの run 分割、画面外、非表示シート上）、グラフ（タイトル・軸・系列名）、画像の代替テキスト、文書プロパティ（core/app/custom）、上記以外の全XMLパーツ（取りこぼし防止）。暗号化ファイルの検出。
